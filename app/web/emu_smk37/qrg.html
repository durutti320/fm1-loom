SPIDER / REAPER mode

Reverse · DAW mode, CC MAP on REAPER: a Mackie Control surface for REAPER · branch spider2 (beta), 6 November 2026

Try it in the emulator first: < + >, PATCH held + K6 to REAPER, then Pretend REAPER

Turn it on

1< + >: DAW mode (SPIDER's sequencer stops)
2PATCH held, K6 (CC MAP): DEFAULT → USER → REAPER. Kept, DAW mode too
3Waiting for REAPER until it answers; every 3 s SPIDER asks again
Port 1SPIDER SMK-37: keys, drum pads (ch 10), wheels, NAV CCs (ch 16), clock
Port 2Mackie Control both ways: MIDIIN2 / MIDIOUT2 (SPIDER SMK-37) on Windows, SPIDER DAW on a Mac

When it doesn't work

Still waitingThe surface needs port 2 in and out, and port 2 left off in MIDI Devices. CC MAP on REAPER?
Knob does nothingNAV's K2–K6 and K8 right only work once learnt
Fader does nothingIt's waiting to pick up: move it past REAPER's level
CCs in a takeThe track records all channels: set ch 1 or 10
Wrong tracks< > bank by 8, GLOBE + by 1; the screen's TRACKS says which

The screen

  1. Transport (recording red), loop, click; the time
  2. Strips 1–8: name, pan, meter; the faders' four framed
  3. Filled selected · faint muted · red dot armed · amber soloed
  4. TRACKS · PADS page · MIX or NAV · OCT; the last control; hints

Set up REAPER (once)

1Preferences → Audio → MIDI Devices: SPIDER SMK-37 in on (and for control messages), out on. Port 2: leave off here
2Control/OSC/web → Add → Mackie Control Universal: in and out port 2. Map F1–F8 to markers off. The screen leaves Waiting
3Actions → Show action list: pick an action, Add…, turn the NAV knob or hit the ACTIONS pad
4Recording tracks: input SPIDER SMK-37, ch 1 (keys) or 10 (pads), so NAV's ch 16 stays out

SPIDER in time with REAPER

Out of DAW mode, CLOCK on receive. In REAPER, the SPIDER SMK-37 output: Send clock (and SPP). Play from anywhere: SPIDER's tracks start at the step they would be on
Mackie numbers are decimal, on port 2, ch 1. SPIDER's side: app/smk_mcu.h · REAPER's: reaper_csurf/csurf_mcu.cpp · more: SMK37.md, The REAPER profile Two-sided: flip on the short edge
