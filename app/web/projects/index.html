Projects

SPIDER keeps two projects on the SMK-37. Here you can name them, swap them, keep copies on this computer, and put a saved one back in either slot.

Connect the SMK-37 by USB with SPIDER running and stopped, close REAPER and anything else using its MIDI ports, and use Chrome or Edge on a computer.

Not connected.

Not on SPIDER yet.

  1. Stop SPIDER if it's playing.
  2. Press Send to SPIDER.
  3. SPIDER asks RESTORE FROM USB? on its screen. Press SCALE for yes (PATCH is no).

Library

Projects kept in this browser, on this computer. They stay when you close the page, but clearing the browser's site data removes them, so save the ones that matter as files too.

Good to know

  • Nothing changes on SPIDER until you press Send and say yes on its screen. SPIDER checks the whole transfer first: a pulled cable or a damaged file changes nothing.
  • Names live with the project, but SPIDER's own screen still calls them Proj 1 and Proj 2.
  • A project uses your samples by name. A project file doesn't carry the samples: keep those on the samples page.
  • Your user presets aren't touched: they go back exactly as they were read.
